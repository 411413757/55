# ♻️ 垃圾分類助手

一個功能完整的手機應用程式，幫助您正確分類垃圾。使用純前端技術開發，無需後端伺服器。

## 功能特性

### 🔍 搜尋分類
- 輸入垃圾名稱即可快速查詢分類方式
- 常見物品快速查詢按鈕
- 實時搜尋結果展示
- 詳細的分類提示

### 📋 分類清單
- 四大主要垃圾分類：
  - ♻️ 可回收垃圾
  - 🌱 廚餘/生物垃圾
  - 🗑️ 一般垃圾
  - ⚠️ 有害垃圾
- 每個分類包含 10+ 個常見物品
- 點擊卡片查看詳細信息

### 📊 查詢紀錄
- 自動保存查詢歷史（最多 50 項）
- 使用瀏覽器本地存儲實現
- 支持刪除單條記錄或清除全部
- 顯示查詢時間

## 垃圾分類說明

### ♻️ 可回收垃圾
包括：寶特瓶、紙箱、玻璃瓶、鋁罐、報紙、雜誌、牛奶盒、舊衣物等

**處理方法：**
- 清空容器內的物質
- 如可能，清洗乾淨
- 壓扁大型物品以節省空間

### 🌱 廚餘/生物垃圾
包括：食物殘渣、果皮、菜葉、骨頭、茶葉渣、咖啡渣等

**處理方法：**
- 瀝乾水分以減少重量
- 移除包裝和非食品垃圾
- 避免投放油膩的食物

### 🗑️ 一般垃圾
包括：塑膠袋、紙尿褲、衛生紙、膠布、陶瓷碎片等

**處理方法：**
- 無法回收或分解的物品
- 放入指定的一般垃圾桶
- 確保物品不含有害物質

### ⚠️ 有害垃圾
包括：電池、熒光燈、油漆、農藥、醫療廢棄物、手機、電子產品等

**處理方法：**
- 需要小心妥善處理
- 防止洩漏和污染環境
- 使用密閉容器盛放
- 查看本地有害廢物回收點

## 使用方法

### 線上使用
1. 使用任何現代瀏覽器打開 `index.html`
2. 應用將自動加載
3. 選擇標籤進行不同操作

### 本地使用
您可以：
- 直接在瀏覽器中打開 HTML 文件
- 使用本地伺服器（如 Python 的 `http.server`）
- 發佈到網絡伺服器

**用 Python 運行本地伺服器：**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

然後訪問 `http://localhost:8000`
